# 英语角常见问题（演示）

Q1、英语角是否只接受英语专业同学？
不是。演示招新方案面向希望练习英语口语和交流的在校同学。

Q2、口语不熟练会不会跟不上？
可以选择入门小组，使用主题词汇卡和简单句表达。活动鼓励参与，不把语言错误作为负面评价。

Q3、参加前应该准备什么？
准备简短英文自我介绍，并围绕通知中的主题写下三条观点或问题。

Q4、英语角有哪些活动形式？
可以开展主题讨论、两人情景对话、电影片段交流和一分钟分享，实际形式以活动通知为准。

Q5、活动是否提供考试辅导或分数保证？
本文描述口语交流活动，不承诺考试辅导结果或分数提升。

Q6、如何提出下次活动的主题？
在活动打卡建议中填写主题，并说明希望练习的场景，例如面试、自我介绍或学术交流。
