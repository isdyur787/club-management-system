# 环保社志愿活动与招新指南（演示）

本文为系统演示资料，具体志愿活动与校内管理要求以正式通知为准。

## 社团方向与成员分工
环保社关注校园减废、垃圾分类、旧物循环和绿色生活宣传。成员可参与活动策划、宣传设计、物资整理、现场记录与数据汇总，不要求已有环保项目经历。

## 推荐活动准备
垃圾分类宣传可先确认校园现行分类规则，再准备说明材料和互动问题；旧物交换活动应明确接收范围、物品检查与未交换物品的处理方式。不得将演示文档中的举例视为学校正式分类标准。

## 现场协作
活动前确认物资、分工、集合位置和联络方式。现场注意保持通道畅通，对不适合由学生处理的废弃物及时联系校内相关管理人员，不擅自处置危险物品。

## 记录与复盘
活动结束后可汇总参与人数、物资流转数量和成员反馈。发布宣传内容时应说明数据的统计口径，不编造减排结果。打卡建议可以聚焦指引是否清晰、物资是否充足和回收流程是否顺畅。
