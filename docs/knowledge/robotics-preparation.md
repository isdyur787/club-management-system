# 机器人创新社申请与筹备说明（演示）

## 当前阶段
当前数据库中的机器人创新社处于待审批状态。本文仅供社团申请与系统演示使用，不表示社团已经成立，也不构成活动招募通知。

## 拟开展的方向
申请方案可以围绕机器人基础结构、传感器认知、编程控制和小组作品展示设计入门活动，面向对机器人制作与编程感兴趣的同学。

## 申请材料准备
建议完善成立目的、负责人分工、指导资源、活动计划、场地与设备需求、经费说明以及活动安全安排。涉及实验设备的活动，应在获得场地和设备管理方许可后进行。

## 审批前后的安排
审批前可以完善材料和收集非正式意向，不以正式社团名义开展已获批准的活动宣传。审批通过后，再根据系统中实际开放的活动提交报名；参与时间、名额和材料以届时通知为准。

## 常见问题
目前能否认为已经加入正式社团或获得竞赛名额？不能。请以社团审批结果、成员状态和正式活动通知为准。
