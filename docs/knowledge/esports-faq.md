# 电竞社常见问题（演示）

Q1、不参加比赛也能加入电竞社吗？
可以。演示方案包含赛事组织、解说、直播制作、赛程记录和宣传等分工。

Q2、团队赛事报名需要准备什么？
建议准备队名、队长联系方式、成员名单和可参加时段，具体要求以活动通知为准。

Q3、是否允许外挂或代打？
不允许。演示赛事组织方案以公平竞技为基本约定，争议按已发布的赛事规则处理。

Q4、训练会影响课程安排吗？
建议在不影响课程的时段进行有明确时长的训练。成员应根据自己的学习安排选择是否报名。

Q5、比赛出现设备或网络问题怎么办？
及时通知活动负责人，记录问题出现的时间与现象，由负责人按赛前公布的中断处理规则协调。

Q6、赛后打卡应该写什么？
可以记录团队沟通、战术配合和组织体验，并提出具体改进建议，避免人身攻击。
