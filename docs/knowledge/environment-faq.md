# 环保社常见问题（演示）

Q1、没有志愿经历可以加入环保社吗？
可以。演示方案设置宣传设计、物资整理、现场记录和数据汇总等多种分工。

Q2、环保社可以开展哪些活动？
可策划校园垃圾分类宣传、旧物交换、减废实践和绿色生活分享，实际项目以活动通知为准。

Q3、垃圾分类应依据什么规则？
应先确认学校或当地当前执行的分类要求。本文不替代正式分类标准。

Q4、旧物交换活动需要提前明确什么？
需要明确接收范围、物品检查、登记方式和未交换物品的后续处理。

Q5、可以自行处理危险废弃物吗？
不应擅自处理。发现不适合由学生处理的物品，应联系校内相关管理人员。

Q6、活动总结可以记录哪些数据？
可以记录参与人数、物资流转数量和成员反馈，同时说明统计口径，不编造减排成果。
