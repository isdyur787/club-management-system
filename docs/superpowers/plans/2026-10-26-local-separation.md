# 前后端独立运行配置计划

**目标：** 沿用已有 Vue 3 + Spring Boot 3 架构，配置并实际运行社团管理功能。

**范围：** 前端独立开发/构建；Java 通过 REST/JWT 提供业务接口；本次不启用 Python AI 服务。

**决定：** 不搬动现有业务目录，避免影响包路径及项目文档。项目专用 MySQL 使用 3307，数据保存在 `.runtime/mysql/`，不更改系统 MySQL。前端默认直接请求 8081，支持通过环境变量切换为代理访问。

- [x] 补充跨域预检回归测试，先确认现有安全链拒绝跨域。
- [x] 后端读取本地环境文件，连接参数可配置，安全链处理允许来源的跨域请求。
- [x] 前端普通请求和 SSE 共用可配置接口地址；Vite 正确读取环境文件。
- [x] 增加本地启动/停止/状态脚本，初始化独立 MySQL 和 Redis，记录 SQL 版本并避免重复导入。
- [x] 完成 Maven 测试、前端构建和接口验证，浏览器实际登录并检查业务页面。
- [x] 编写本地运行说明，交付访问地址、测试账号及操作命令。

验证重点：允许来源预检成功，非允许来源被拒绝，鉴权继续生效；重新启动保留数据；登录后读取真实数据库；AI 未配置不影响主要业务。

验证结果：后端 90 项测试通过；前端构建通过（保留原有 bundle 体积提示）；Chrome / Playwright 验证登录及社团、活动、资源、通知、统计、积分页面，28 次接口请求成功，无页面错误、控制台警告和请求失败。独立空库完成 V1–V12 初始化并验证再次运行不重复导入；完整停止/重启后 76 个用户、10 个社团、40 个活动、337 条报名及 12 条迁移记录保持一致。构建预览的同源代理登录通过。只读审查发现的环境变量优先级和数据库地址分流问题已修复。
