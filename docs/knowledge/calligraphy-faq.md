# 书法协会常见问题（演示）

Q1、零基础可以参加书法协会吗？
可以。演示入门活动从执笔、基本笔画和简单结构练习开始。

Q2、书法活动只练毛笔字吗？
演示方案可安排毛笔与硬笔书写、临帖交流、作品点评和校园展览，具体内容以通知为准。

Q3、第一次活动要准备哪些材料？
查看通知中的纸、笔、墨等要求。若活动提供共享材料，请提前确认领取和归还方式。

Q4、临帖时应该如何记录练习？
建议记录练习日期、所临字帖与本次重点，比较笔画、结构和章法后再做针对性练习。

Q5、参加展览需要填写什么？
建议填写作者、作品名、创作说明，并注明引用诗文的来源。展览规格与提交时间以正式通知为准。

Q6、可以公开分享其他成员的作品吗？
请先获得作者同意，并保留正确署名。
