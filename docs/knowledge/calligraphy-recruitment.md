# 书法协会入门与招新指南（演示）

本文为演示资料，正式课程、材料和展览安排以社团通知为准。

## 入门与社团活动
书法协会欢迎对毛笔、硬笔书写和传统书法文化感兴趣的同学。入门体验可以从执笔、基本笔画和简单结构练习开始，后续安排临帖交流、作品点评与校园展览。

## 首次活动准备
按通知准备适合练习的纸、笔和墨等材料；如果社团安排共享材料，请在报名时确认领取与归还方式。作品旁可记录日期、所临字帖和自己的练习重点，便于观察进步。

## 建议练习方法
围绕一个笔画或一个结构问题做短时练习，先观察字帖，再临写、比较与记录。作品交流时讨论线条、结构和章法，尊重不同的学习阶段，不以单次作品评判成员水平。

## 作品展示与空间维护
提交展览作品时填写作者、作品名和创作说明，引用诗文需注明来源。未经同意不代替他人署名。使用教室后清理墨迹与桌面，按要求整理共享物品。
