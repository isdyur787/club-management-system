# 街舞社常见问题（演示）

Q1、没有舞蹈基础可以加入街舞社吗？
可以。演示方案设置基础律动入门组，先学习节拍、重心和简单动作，再逐步参与组合练习。

Q2、第一次体验课需要准备什么？
准备方便活动的服装、运动鞋和饮用水，提前查看活动通知中的排练室位置和时间。

Q3、社团训练主要有哪些环节？
建议包括热身、基础律动、动作拆解、组合练习和整理反馈，具体内容由活动负责人发布。

Q4、能否直接练习高难度动作？
应根据自身能力循序渐进，在有指导和适当场地的条件下练习，避免自行模仿危险动作。

Q5、可以上传同学的练舞视频吗？
请先征得视频中成员的同意。活动打卡可以记录自己的学习心得，不要求公开他人的影像。

Q6、如何参加编舞或演出？
关注社团活动通知，按报名要求提交意向。演出选拔、排练次数和时间以实际通知为准，本文不构成演出名额承诺。
